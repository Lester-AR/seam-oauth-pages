# Privacy Policy — SEAM Evidence Pipeline

**Last updated: October 22, 2026**

## 1. Purpose

SEAM Evidence Pipeline is a private financial research project. Its Google Drive integration is used to archive and verify research evidence files.

## 2. Google Account Access

The application uses Google OAuth 2.0 with the `drive.file` permission.

This permission allows the application to access specific Google Drive files authorized for use with the application, rather than granting unrestricted access to the user's entire Google Drive.

## 3. Data Processing

The application processes files and associated metadata necessary for research evidence archival, integrity verification, and retrieval.

This may include file identifiers, names, sizes, cryptographic checksums, and verification results.

## 4. Data Storage and Sharing

Authorized research files are stored in the project owner's Google Drive account.

The application is not intended to sell personal information or share Google user data with advertisers.

Google OAuth credentials and access tokens are managed as confidential credentials.

## 5. Data Retention and Deletion

Research files are retained according to the project owner's archival requirements.

The project owner can delete files from Google Drive and revoke application access through Google Account security settings.

## 6. Security

The application uses OAuth authorization and restricted repository secrets to support authenticated access.

## 7. Contact

Privacy inquiries may be directed to the application support email listed on its Google OAuth consent screen.
