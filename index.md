
# SEAM Evidence Pipeline

SEAM Evidence Pipeline is a private financial research project.

This public website provides information about the project's Google Drive integration.

The application uses Google OAuth to archive and verify research evidence files in Google Drive.

Access is limited to files authorized for use with the application.

The application is intended for use by its project owner and is not offered as a public service.

For support or privacy inquiries, contact the project owner through the Google OAuth application support email.
